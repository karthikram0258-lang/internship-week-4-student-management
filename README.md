# Week 4 - Student Management Dashboard 🎓

A front-end Student Management Dashboard developed using HTML, CSS, and JavaScript.

## Features

- Add student data
- Edit student data
- Delete student data
- Store student data using localStorage
- Display students in a styled table
- Search students by name, roll number, or course
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- DOM Manipulation
- localStorage

## CRUD Operations

- **Create** - Add new student records
- **Read** - Display student records
- **Update** - Edit existing student records
- **Delete** - Remove student records

## How It Works

1. Enter the student's name, roll number, course, and year.
2. Click **Add Student**.
3. The student is displayed in the table.
4. Student data is stored in the browser's localStorage.
5. Use **Edit** to update a record.
6. Use **Delete** to remove a record.
7. Use the search box to find students.
